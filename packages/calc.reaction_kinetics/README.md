# calc.reaction_kinetics@0.1.0

Shared Arxo numerical primitives for concentration bounds, half-life and Arrhenius calculations. The chemistry adapter supplies the run input and precision; arithmetic remains in the engine.

This technical dependency is included in the kinetics world. It declares no native scenario suite; its numerical behavior is exercised through [kinetics](../openstax.chemistry_kinetics/tests/02-kinetic-run.lawtest). No textbook section denominator is declared, so source depth remains `not_measured`.
